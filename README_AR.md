# OSM Smart Coin AI — النسخة 0.2.0

تطبيق Android أولي يراقب الشاشة بموافقة صريحة من المستخدم، ويستخدم ML Kit OCR محليًا للتعرّف على بعض نصوص واجهة OSM أو إشارة إلى إعلان. لا توجد خدمة سحابية ولا تُرفع صور الشاشة من هذا التطبيق.

## ما الذي يفعله؟
- طلب إذن مشاركة الشاشة من نظام Android قبل بدء كل جلسة مراقبة.
- معالجة لقطات الشاشة على الجهاز باستخدام ML Kit Text Recognition.
- التعرف على نصوص مثل `Start video` و`free Boss Coins` وبعض إشارات الإعلان وواجهة المباراة.
- عرض آخر حالة في التطبيق وتحديث إشعار المراقبة عند تغيّر الحالة.
- يطلب الإيقاف من داخل التطبيق، وتستطيع أيضًا إيقاف مشاركة الشاشة من إشعار النظام.

## ما الذي لا يفعله؟
- لا يضغط على أي زر، ولا يبدأ الفيديو أو يغلق الإعلان أو يتجاوز أي تفاعل.
- لا يستطيع إثبات اكتمال مشاهدة الإعلان أو التأكد من وصول Boss Coins؛ يجب التحقق داخل OSM بنفسك.
- التعرف على الشاشة تجريبي وقد يفشل بسبب اختلاف الإصدار أو اللغة أو حجم النص أو تصميم الإعلان.

## فتح وبناء المشروع
1. افتح Android Studio (أو استخدم بيئة Android بديلة تدعم Gradle) وافتح هذا المجلد.
2. اسمح بتنزيل Android SDK / Gradle حين يطلبه البرنامج. يتطلب المشروع Android SDK Platform 36.
3. انتظر Gradle Sync. إذا ظهر خطأ، انسخ نص الخطأ كاملًا بدل تغيير الإصدارات عشوائيًا.
4. وصّل هاتف Android عبر USB، وفعّل خيارات المطوّر وUSB debugging، ثم اضغط Run.
5. داخل التطبيق اضغط «ابدأ التعرّف على الشاشة» ووافق على مربع مشاركة الشاشة الذي يعرضه Android.
6. انتقل إلى OSM. يظل إشعار المراقبة ظاهرًا أثناء عمل الجلسة. للإنهاء، ارجع للتطبيق واضغط «إيقاف المراقبة».

## ملاحظات Android
- يستخدم المشروع MediaProjection؛ يفرض Android موافقة المستخدم لبدء كل جلسة تسجيل شاشة، ويتطلب خدمة أمامية من نوع mediaProjection على الإصدارات الحديثة.
- أُضيفت مراقبة أساسية فقط. يجب اختبارها على جهاز فعلي لأن دقة الشاشة وتوفير الطاقة وقيود الشركة المصنّعة تختلف.

## بديل عن تثبيت Android Studio (اختياري)

يمكن بناء APK سحابيًا عبر ملف GitHub Actions المرفق، لكن ذلك يتطلب حساب GitHub ورفع ملفات المشروع إلى مستودع، ثم تشغيل إجراء **Build Android APK** من تبويب Actions. عند نجاحه نزّل artifact باسم `osm-smart-coin-ai-debug-apk`. يجب تثبيت APK على هاتفك بنفسك.
